How it works

Countries

Chawanikwa works in Zimbabwe, South Africa and the USA. Choose the country first. Phone numbers, places and the ID characters we ask for change with the country. Reports only match inside the same country.

If you lost an ID

Search by name or the last 5 characters. If you see it, start a claim. If not, register it as lost and we will contact you if it is reported.

If you found an ID

Report the name and last 5 characters. Do not photograph the ID or share it online. A team member reviews each report before it appears in search. We do not say a report is genuine until it has been checked.

Handover

We only hand an ID over after an agent sees the owner's official identity documents in person (for example a Passport, Driver's Licence or Birth Certificate) and the name matches. Every step is recorded.
